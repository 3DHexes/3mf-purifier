# Changelog

## 1.0.1

- Help window shows the license (GNU GPL v3.0) and a link to the source code.
- Clearer help texts: names are kept in Universal mode too; fixes in the Polish help.
- Download packages include LICENSE.txt and NOTICE.txt.
- Package texts are now kept in the packaging/ folder.

## 1.0.0 (2026-11-22)

First public release.

- Three modes: No filaments, With filaments (OrcaSlicer Publish 3MF) and Universal (plain 3MF for PrusaSlicer, Cura and others).
- Universal mode keeps color painting and per-part extruders for PrusaSlicer and can split multi-plate projects into one file per plate.
- Option to save the Universal copy together with the OrcaSlicer file.
- Privacy cleanup of full source paths and MakerWorld print-profile data.
- Optional author, license and copyright fields.
- Custom cover thumbnail from an image or rendered from the 3D preview.
- 3D preview of source and result, batch processing of folders, drag and drop.
- Interface and help in English, Polish, German, French and Spanish.
